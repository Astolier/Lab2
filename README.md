## 三、主要功能特性
1. **界面与交互**：
   - 混合式 UI 设计，采用垂直布局并将边距（Margins）设为 0，实现编辑区域无缝贴合。
   - 菜单栏（文件、编辑、格式、查看、帮助）与工具栏功能分组明确，图标规范统一。
   - 状态栏实时统计字符总数（`length`）、总行数（`lines`）、当前光标所在行（`Ln`）与列（`Col`），右下角常驻显示开发者姓名。
2. **文本编辑与文件操作**：
   - 支持文件的新建、打开、保存、另存为与安全退出机制。
   - 具备完整未保存数据提示（`maybeSave` 拦截），支持打开异常/不存在文件时的错误捕获提示。
   - 支持撤销（Undo）、重做（Redo）、剪切（Cut）、复制（Copy）、粘贴（Paste）、全选（Select All）。
   - Action 使能状态联动：根据编辑器选区及剪贴板内容实时置灰/激活对应操作按钮。
3. **格式与查看**：
   - 自动换行切换、行号显示/隐藏切换。
   - 字体设置（`QFontDialog`）、字体颜色、字体背景色与编辑器背景色自定义。
   - 工具栏与状态栏显示/隐藏切换。
4. **多窗口对话框**：
   - **关于对话框 (AboutDialog)**：展示应用大标题、应用图标、开发者、学号、邮箱与版本号。
   - **查找对话框 (FindDialog)**：支持向上/向下方向搜索、区分大小写匹配与未找到提示。
   - **替换对话框 (ReplaceDialog)**：支持单次替换与全部替换，单次替换最后一处时平滑停留且不误报未找到；全部替换采用原子事务块处理并准确统计替换数量。
5. **CodeEditor 提升控件**：
   - 派生自 `QPlainTextEdit`，实现自适应宽度的行号栏绘制。
   - 当前光标所在行高亮浅黄色背景条。

## 四、编译与运行
使用 Qt Creator 打开 `mynotepad.pro`，选择 `Desktop Qt 5.12.11 MinGW 64-bit` 套件，点击构建并运行即可；或者在命令行中执行：
```bash
qmake
mingw32-make
./release/mynotepad.exe
```
